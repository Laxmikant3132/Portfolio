# Laxmikant Talli | Professional Portfolio

A premium, high-performance personal portfolio website built for **Laxmikant Talli**, a BCA student and Frontend Developer. This project showcases a modern design with advanced animations, a glassmorphism UI, and a fully functional contact system.

## 🚀 Live Demo
Check out the live project here: [https://laxmikant3132.github.io/](https://laxmikant3132.github.io/) (Replace with your actual link)

## ✨ Key Features
- **Modern Galaxy Background**: Interactive space-themed background with nebulae and moving stars.
- **Bento Grid Skills**: A modern layout showcasing technical expertise with hover glow effects.
- **Interactive Journey Timeline**: Scroll-triggered timeline documenting academic and professional growth.
- **Project Showcase**: Detailed cards for selected work with live demo and source code links.
- **Functional Contact Form**: Integrated with **EmailJS** for real-time email notifications directly to your inbox.
- **Custom Cursor**: Smoothly following custom cursor for enhanced user experience.
- **Fully Responsive**: Optimized for all devices, from high-end desktops to mobile phones.

## 🛠️ Technologies Used
- **HTML5**: Semantic structure for better SEO and accessibility.
- **CSS3**: Advanced styling, including Flexbox, Grid, Custom Properties, and Keyframe animations.
- **JavaScript (ES6+)**: Custom logic for animations, typed text effects, and intersection observers.
- **EmailJS**: For serverless email handling.
- **Font Awesome**: Premium iconography.
- **Google Fonts**: Plus Jakarta Sans for a modern look.

## 📦 Setup & Installation

To run this project locally:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Laxmikant3132/Assignment.git
    ```
2.  **Open the project**:
    Simply open `index.html` in your favorite web browser.

## 📧 Contact Configuration

To use the contact form for your own email, update the following placeholders in `script.js`:

```javascript
// Initialize EmailJS with your Public Key
emailjs.init("YOUR_PUBLIC_KEY");

// Update these in the submit event listener
const serviceID = 'YOUR_SERVICE_ID';
const templateID = 'YOUR_TEMPLATE_ID';
```
